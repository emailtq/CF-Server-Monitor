Parent evaluates the actual page handler expression from its AST with the real composable and an owned delayed clipboard fixture: 17 old-command bytes are sent to the fresh WebSocket instead of zero. Capture and check the originating session/generation before consuming the result, including focus/error effects; discard late results on close, exit, disposal or reopen. Keep the existing size/credit/IME/paste transformations and no-replay behavior.
- [P2] Preserve queued final output across normal exit (`src/frontend/composables/useTerminal.js:270`, `src/frontend/composables/useTerminal.js:78`). The exit message immediately invokes stop, which increments the generation and disposes xterm. A preceding binary frame may still be awaiting xterm's asynchronous write callback; it is discarded, and the already rendered terminal is also removed. Parent feeds final output followed immediately by exit 0 without consuming the queued callback: xterm is disposed before consumption. Separate remote/session teardown from rendering teardown, preserving a bounded final write/render boundary and read-only result without keeping the PTY/socket alive. Dispose on explicit reopen/page disposal as appropriate; do not add detached replay, unbounded tail queues or continued input.
