## Original Finding And Repair

- [P1] Observe Shell completion independently of PTY EOF (`internal/cfprobe/terminal_session.go:406`). The process Wait result is consumed only after the output reader reports EOF. A child can retain the slave descriptor after the Shell exits, leaving the PTY reader blocked. With no unacknowledged output or pending input, the stall watchdog has no deadline either. The session/peer/slot therefore stay live indefinitely despite completed Shell Wait, instead of delivering the exit and cleaning up. React to process completion with bounded output-drain/cleanup while preserving trailing output, exit code, single Wait ownership and isolation. Do not wait indefinitely for a descendant to close the slave.
- The repair's writer observes the sole Wait result independently of EOF, allows 500 ms of trailing output, then flushes a finite queue snapshot with a further bounded write budget and ordered exit. Output/ACK activity cannot extend the drain. Linux source captures verified ordinary same-SID process pidfds before the sole reap and uses retained handles afterward rather than rediscovering a reused PID/SID. The original symptom and credit/tail/isolation regressions pass on fake endpoints; the Linux companion now passes on actual Linux, including the independent pinning mutation below.
